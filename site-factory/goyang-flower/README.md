# Flower-local-v2 clean bootstrap

This source tree is a region-neutral renderer skeleton. It contains no approved
regional articles, draft IDs, queue IDs, snapshot IDs, domain ownership proof,
or production credentials. It is never a published site by itself.

Before an isolated new-region preview, copy it to a new registered site root,
then replace `src/data/site-config.json` with that site's key, region, exact
workers.dev staging URL and distinct staging Worker. Set matching `siteKey` in
the architecture, manifest and page map. Do not turn on `productionApproved`.
Replace the staging Wrangler Worker name with the exact new registered Worker;
the template's own name must never be deployed as the region's Worker.
Replace the distinct disabled-production Worker name too. No custom domain or
route is configured or needed for the preview.
The verified flower-fwith Business Truth and catalog are reusable only for the
same business; local delivery, facility acceptance and timing are not implied.
The region-neutral opening wreath illustration is labeled AI editorial artwork
and must never be presented as a real SKU or delivery proof.

With zero approved pages, `npm run build` is allowed only with
`SITE_INDEXABLE=false` and makes an isolated noindex skeleton. Each subsequent
detail must come from a reviewed frozen Publish Queue payload using the common
snapshot adapter. Validate the exact rendered source, prices, photos, CTA,
links, claims, headers and robots before any production decision. The generic
graph/static checks are build gates; Suwon's historical regression fixture is
intentionally absent.
